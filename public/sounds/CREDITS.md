# OUTBREAK Audio

Existing effect recordings are loaded from:

- https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds (CC0)
- https://github.com/PanderMusubi/sound-effects-library-weapons (CC0)

The menu hover creak uses `100-CC0-wood-metal-SFX/door_open_01.ogg`
from the first collection, with reduced volume and playback speed.

The ambient musical score is generated in `src/game/music.ts` using
original oscillator arrangements. It is independent of the effects bus
and does not require an external recording or network connection.
